## 체육복

### 문제 요약

- n명의 학생중 lost 배열의 학생은 체육복을 도난당했고 reserve 배열의 학생은 여벌의 체육복이 있다.
- 여벌의 체육복을 가진 학생은 도난당한 학생들에게 여벌을 빌려줄 수 있는데
- 이때 n명의 학생중에 체육복을 입을 수 있는 학생의 수를 반환하시오.

### 접근 방식

- n + 2개의 배열을 만들고 다 1로 채운다
- lost에 해당하는 학생들에 대해선 각 -1을 해준다.
- reserve에 해당하는 학생들에게는 각 +1을 해준다.
- 이후 여벌이 필요한 학생들에게 체육복을 앞사람부터 빌려준다.
- 최종적으로 체육복을 입을 수 있는 학생의 수를 반환한다.

### 왜 이런 방식으로 풀었나?

- 학생상태를 배열로 표시에 기본 1 도난 -1 여벌 +1로 표시해서 보기 쉽게 정리 후
- 빌려주는 순서를 앞사람부터해서 있으면 뒷사람을 빌려주는 형식으로 개념을 잡았다.
- 그리디 방식으로 푸는게 최선의 방법인거 같아서 해당 방식을 사용했다.
